# Express Book Review

Online book review application built with **Node.js**, **Express**, **express-session** and **JWT**.

## Features
- Get all books, or search by ISBN, author and title (Promises, async/await and Axios)
- Get book reviews
- Register and log in as a customer (JWT stored in the session)
- Add, modify and delete your own book reviews

## Run
```bash
cd final_project
npm install
npm start
```
The server runs on port 5000.
